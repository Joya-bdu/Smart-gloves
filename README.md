HandNav – IoT-Based Smart Navigation Glove



HandNav is an IoT-based smart navigation glove designed to assist visually impaired people with obstacle detection, navigation support, emergency alerts, and GPS-based location tracking.



Project Overview



HandNav is a wearable assistive technology system that combines sensors, wireless communication, and GPS technology to improve the safety and independence of visually impaired people.



The glove detects nearby obstacles and provides warning feedback through a buzzer. In emergency situations, the system can provide location information using GPS.



✨ Key Features



\- Obstacle detection using an ultrasonic sensor

\- Real-time warning through a buzzer

\- GPS-based location tracking

\- Emergency alert functionality

\- Bluetooth communication using HC-05

\- Wearable glove-based design

\- Assistive navigation support for visually impaired people

⚙️ Working Principle



The ultrasonic sensor continuously measures the distance between the user and nearby obstacles. When an obstacle is detected within a predefined range, the system activates the buzzer to provide an audio warning.



The GPS module is used to obtain location information during emergency situations, while the HC-05 Bluetooth module provides wireless communication.
